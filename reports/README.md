# Audit evidence package — SYNTHETIC

All amount columns ending in `_cents` are integer USD cents. Convert for reading by dividing by 100. Workbooks preserve cents as numeric integers; they do not contain macros or external connections.

- `audit_workpapers.xlsx`: reconciliation, bridge, aging, customer risk, KPIs, revenue reconciliation, support checks, exceptions, controls and scope.
- `risk_control_matrix.xlsx`: assertion, evidence, logic, threshold, severity, exposure basis, false positives, investigation, remediation owner and proposed target.
- CSVs: the corresponding detail tables for independent review.
- `summary.json`: actual generated totals and transaction database SHA-256.
- `sql_validation.json`: executed SQL/SQLite checks and explicit Python/Streamlit verification status.
- `executive_findings.md`: quantified case results, limitations and prioritized proposed remediation.
- `detection_evaluation.csv`: separate answer-key comparison; fixture validation only.
- `publication_review.json`: initial content scan, XML/numeric workbook checks and publication status.
- `pytest_results.xml`: 38 passing Python tests, with local hostname omitted.
- `browser_validation.json`: actual tab rendering, screenshots and CSV/Excel download checks.
- `reproducibility.json`: identical logical source rows across independent generation.
- `manifest.json`: SHA-256 checksums for all other report files present at generation time.

The final CSV/XLSX artifacts were generated by the executed Python pandas/openpyxl pipeline. Earlier SQL validation used the same financial queries via a native SQLite/Ruby fallback. `python -m revenue_audit analyze` regenerates workpapers; validation should be rerun after changing data or logic. The included JUnit report records 38 passing tests, and browser_validation.json records actual UI and download checks.

Amounts are potential exposure or extract discrepancies, not confirmed fraud, real audit findings, proven misstatements or losses. Rule subtotals overlap. Use `summary.json`'s deduplicated envelope rather than adding rule exposure totals. These workpapers do not include independent source-system completeness evidence.
